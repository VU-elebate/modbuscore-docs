ModbusCore++

A C++20 Modbus library targeting embedded systems (FreeRTOS) and desktop (Linux/Windows). Supports both TCP/IP and Serial (RTU) transports via a pluggable communication layer.

Architecture

ModbusCore::Device<T> (CRTP base — T is Server or Client)
├── ModbusCore::Server (slave: receives and responds to requests)
└── ModbusCore::Client (master: sends requests, processes responses)
ModbusCore::Communication (abstract transport layer)
├── Your TCP/IP implementation
└── Your Serial implementation

See DESIGN.md for a full design overview.

Building

cmake -S . -B build/ -D CMAKE_BUILD_TYPE=Debug
cmake --build build/

CMake options:

Option Default Description
MODBUS_TESTS ON Build the Google Test suite
MODBUS_COMMUNICATION ON Build the communication layer
MODBUS_EXAMPLE OFF Build example programs

Run a single test:

./build/tests/modbusCore_tst --gtest_filter='SuiteName.TestName'

Usage

1. Implement a transport layer

Subclass ModbusCore::Communication and implement readData and writeData for your hardware:

class MySerialPort : public ModbusCore::Communication
{
public:
ModbusCore::ModbusErrorCode readData(ModbusCore::PDU &frame) override
{
// Read one ADU from the serial bus.
// Push the sender's address into addressesFIFO before returning Acknowledge.
}
ModbusCore::ModbusErrorCode writeData(ModbusCore::PDU &frame, ModbusCore::AddressType address) override
{
// Wrap frame in an ADU and transmit it.
}
};

2. Server (slave)

MySerialPort port;
ModbusCore::Server server(/*address=*/1, /*discreteInputs=*/2000, /*coils=*/2000,
/*inputRegs=*/2000, /*holdingRegs=*/2000, &port);
// Pre-populate memory
server.writeMultipleCoils(0x13, 8, 0xCD);
server.writeHoldingRegister(0x6B, 0x022B);
// Call from your application loop — one state-machine step per call
while (true)
server.processRequest();

3. Client (master)

MySerialPort port;
ModbusCore::Client client(/*address=*/1, 2000, 2000, 2000, 2000, &port);
ModbusCore::PDU request;
request.function = ModbusCore::ModbusFunctionCode::ReadCoils;
request.data = {0x00, 0x13, 0x00, 0x13};
client.createRequest(/*destination=*/1, request);
// Blocks until a full response cycle completes
ModbusCore::PDU response = client.processRequest();
